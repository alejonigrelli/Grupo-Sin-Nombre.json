# Documentación del Proyecto (Carpeta /client)

Este proyecto corresponde a la carpeta `/client`, donde se está desarrollando por el momento el frontend de la aplicación utilizando [Create React App]


Dentro de la carpeta `/client`, se debe ejecutar el siguiente comando en la terminal:

### `npm start`

Inicia la aplicación en modo desarrollo.\
Abrí [http://localhost:3000](http://localhost:3000) en tu navegador para verla.
