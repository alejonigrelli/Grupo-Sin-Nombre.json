## Descripcion
Sitio web de e-commerce frontend para una muebleria de muebles de madera. El sitio permite recorrer un catalogo de productos, ver el detalle de cada mueble, simular la compra con un carrito y contactarse a traves de un formulario con validacion.

## Funcionalidades
- Catalogo de productos cargado dinamicamente desde un array de objetos en JavaScript
- Detalle de producto con imagen, descripcion, materiales, dimensiones y precio
- Carrito simulado con contador en el header
- Formulario de contacto con validacion del lado del cliente
- Busqueda de productos por nombre
- Carga asincrona simulada con setTimeout
- Diseño responsivo

## Tecnologias
- HTML5
